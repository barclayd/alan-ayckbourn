This page is a guide to what plays may be suitable for certain productions (such as small cast, specific locations). if you have any other staging parameters which would be suitable for this page, please email: **[admin@alanayckbourn.net](mailto:admin@alanayckbourn.net)**.

### Gender Specific Plays

**○ All Male:** *[Haunting Julia](/plays/haunting-julia)*  
**○ All Female:** *[Snake In The Grass](/plays/snake-in-the-grass)*

### Outdoor Location Plays

Note: This does not include plays where any scene is set indoors (i.e. *Relatively Speaking*) or the outdoor set includes a portion of an indoor set (i.e. *Time & Time Again*) or which could never feasibly be staged outdoors (i.e. *Way Upstream*)
